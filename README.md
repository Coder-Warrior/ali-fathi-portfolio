# Ali Fathi — Portfolio

Kinetic Dark style developer portfolio. Cinematic preloader, custom cursor, animated name intro, and a real case study for every project.

## Owner
**Ali Fathi** — 17-year-old self-taught developer from Alexandria, Egypt.

## Stack
- HTML5
- CSS3 (custom properties, grid, no framework)
- Vanilla JavaScript
- Google Fonts: Anton + Space Grotesk + JetBrains Mono

## Pages
- `index.html` — Hero, stats, work, about, contact
- `work.html` — Full list of all projects
- `case-study.html` — Single project case study (via `?project=ID`)
- `cv.html` — Printable CV (Ctrl+P → Save as PDF)

## Signature features
- **Cinematic preloader** — name animates letter-by-letter
- **Custom cursor** with smooth follow + hover state
- **Kinetic typography** — Anton display font, gradient accents
- **Vertical marquee** — scrolling giant text background
- **Dark only** (intentional — Kinetic style)
- **Scroll reveals**, animated counters, parallax orbs
- **Print-ready CV** with dedicated print CSS
- **Zero dependencies**
